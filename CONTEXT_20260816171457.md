### File Summary
This project automates fetching, displaying, and setting NASA's Astronomy Picture of the Day (APOD) as desktop backgrounds. It consists of a primary Bash script (`fetch-images-NASA.sh`) and supporting utility scripts to download images, manage paths, display images in galleries, and configure system cron jobs. The project interacts with NASA's APOD API, local filesystem for storage, and system tools like `eog` (Eye of GNOME) for image display and `cron` for scheduling.

---

### Key Components

#### **Primary Script: `/fetch-images-NASA.sh`**
- **Imports/Dependencies:**
  - `bash`: Core shell interpreter.
  - `curl`: Fetches HTML/image data from NASA's APOD API.
  - `eog`: Displays images in full-screen mode.
  - `identify` (ImageMagick): Extracts image dimensions for aspect ratio validation.
  - Local functions: Dynamically sourced from `functions/resolvers/` and `functions/utils/`.

- **Classes/Functions:**
  - **Main CLI Handler (`getopts` loop)**:
    Parses command-line arguments (`-g`, `-d`, `-p`, etc.) to trigger specific workflows (e.g., download images, set backgrounds).
    - *Example:* `-d 23`: Downloads all APOD images for the year 2023.
  - **Global Variables**:
    - `default_path`: Root directory for storing images/dates.
    - `firefox_var`: Toggle to open HTML metadata in Firefox.
    - `global_seconds`: Default slideshow duration (10s).

#### **Core Resolver Scripts**
1. **`download_image.sh`**
   - `download_image(date: str)`:
     Fetches APOD HTML for a given date, parses the image URL (JPG/PNG), and downloads the image to `$default_path/Images/YYYYMMDD/`. Handles missing URLs by logging failures.
     - *Edge Case*: Skips download if the image already exists.

2. **`get_Dates2.sh`**
   - `get_Dates2(year: str)`:
     Generates a list of valid dates (YYYYMMDD) for a given year, accounting for leap years and the current date. Outputs to `$default_path/Dates/Dates_$year.txt`.

3. **`set_all_wallpapers.sh`**
   - `set_all_wallpapers(year: str)`:
     Displays all images from a year in a randomized slideshow, with each image shown for `global_seconds`. Optionally opens HTML metadata in Firefox.

4. **`display_wallpapers_candidates.sh`**
   - `display_wallpapers_candidates()`:
     Displays images from `wallpapers_candidates2.txt` (16:9 aspect ratio) in a shuffled slideshow.

5. **`last_image.sh`**
   - `last_image()`:
     Fetches the latest APOD image and sets it as the desktop background.

#### **Utility Scripts**
1. **`helpPanel.sh`**
   - `helpPanel()`:
     Prints CLI usage instructions, examples, and option descriptions.

2. **`cronjob_everyday.sh`**
   - `cronjob_everyday()`:
     Configures a daily cron job to download the latest APOD and update the background. Uses `fetch-images-NASA.sh -l`.

3. **`Paths/script1.sh` & `script2.sh`**
   - `image_paths()`:
     Scans `$default_path/Images/` for non-HTML files, filters images with a 16:9 aspect ratio, and writes paths to `wallpapers_candidates2.txt`.
   - *Note*: `script2.sh` is a legacy version with hardcoded paths.

4. **`daily.sh`**
   - `daily()`:
     Wrapper script for systemd timers. Calls `fetch-images-NASA.sh -d 25` (download) and `-l` (set latest background) with logging.

### Notable Patterns/Issues
- **Design Patterns**:
  - **Modularity**: Functions are split into small, single-purpose scripts (e.g., `download_image.sh`, `get_Dates2.sh`).
  - **Dynamic Sourcing**: Imports functions at runtime from `functions/` directories.
- **Anti-Patterns**:
  - **Hardcoded Paths**: Some scripts (e.g., `Paths/script2.sh`) use absolute paths, reducing portability.
  - **Race Conditions**: Background processes (`eog`, `curl`) may conflict if multiple instances run concurrently.
- **Security Risks**:
  - **Unsanitized Input**: `date` parameters in `download_image.sh` are used directly in URLs, risking command injection (e.g., `date="; rm -rf /;"`).
- **Performance Bottlenecks**:
  - **Sequential Downloads**: `download_images.sh` processes dates sequentially, which is slow for bulk downloads. Parallelization (e.g., `&`) is inconsistently applied.
  - **ImageMagick Overhead**: `identify` is called repeatedly for aspect ratio checks, which could be cached.
